# Каталог форм и медицинский раздел

Статус: этап 10. Проверяемость важнее полноты каталога.

Связано: [official-source-policy.md](official-source-policy.md), [legal-and-consent-spec.md](legal-and-consent-spec.md), ADR-0004.

---

## 1. Принципы

1. Форма не публикуется без **approved** official source snapshot, **raw original**, **SHA-256**, номера/даты акта, `valid_from`/`valid_to`, назначения, authority и даты проверки.
2. MVP: одна кандидатная форма МВД добавляется в каталог **только** после фактической проверки официального файла. Если файл недоступен или редакция неясна — **не публиковать**, показать `needs_review`.
3. Медицинский раздел строится только на approved источниках Минздрава / Роспотребнадзора / официальных региональных органов из allowlist.
4. Сервис **никогда** не генерирует официальный сертификат, заключение, справку, результат анализа, диагноз, подпись, печать, QR или номер учреждения. Блокировка на backend.
5. Любой пользовательский PDF из медраздела помечается: «Предварительная анкета/памятка. Не является медицинским документом».
6. Медицинская загрузка — только при действующем `special_categories.medical`; короткий retention; роль доступа `medical_restricted`.

---

## 2. Регистрация формы (editor)

Обязательные поля:

| Поле | Требование |
|------|------------|
| `source_snapshot_id` | Состояние `approved`, применим на дату регистрации |
| `raw_original` | Непустой байтовый оригинал |
| `content_sha256` | Совпадает с SHA-256(`raw_original`) |
| `act_number`, `act_date` | Из метаданных акта / snapshot |
| `valid_from`, `valid_to?` | Интервал актуальности формы |
| `purpose` | Назначение (миграция, виза, …) |
| `authority` | Орган |
| `reviewed_at`, `reviewer` | Дата и субъект editorial review |

Без любого из пунктов → отказ регистрации. Опубликованный статус только `published`; иначе `needs_review` / `draft`.

---

## 3. Каталог (публичный список)

Фильтры: `organ`, `purpose`, `status`, `region`, `as_of` (актуальность).

Карточка: источник, редакция (акт), дата проверки, предупреждение (не гос-сервис / needs_review).

---

## 4. Медицинский раздел

- Процедура: объяснение + кому применимо + сроки **только** из approved source.
- Уполномоченные организации: регион + `reviewed_at`; **не** показывать вне `valid_from`/`valid_to`.
- Артефакты: `questionnaire` | `checklist` | `memo` только.
- Запрещённые kind → HTTP 403 даже при прямом API-вызове.

---

## 5. Abuse / outdated

`POST /forms/abuse-reports` — форма, источник, мед. процедура/организация устарела или злоупотребление. Append-only, без авто-изменения каталога.

---

## 6. Retention / доступ

| Вид | Оригинал (по умолчанию) |
|-----|-------------------------|
| Обычный документ | `RETENTION_ORIGINALS_DAYS` |
| Медицинский | `RETENTION_MEDICAL_ORIGINALS_DAYS` (короче, default 7) |

Доступ к мед. документу: владелец или роль `medical_reviewer`; иначе 403.
